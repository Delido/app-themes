# Aurora fuer VS Code

Deep-Space-Schwarz mit Aurora-Akzent, passend zum TeamSpeak-Theme Aurora. Varianten: Ice, Mint, Violet, Ember, Rose.

Bauen: `node build.js`, packen: `npx @vscode/vsce package --allow-missing-repository --skip-license`, installieren: `code --install-extension aurora-theme-1.0.0.vsix`.
